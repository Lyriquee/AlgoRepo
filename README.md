# AlgoRepo

**AlgoRepo** 是一个基于纯 C 语言开发的个人算法题代码仓库管理系统，用于统一管理、组织和维护算法题代码。

## 如何编译

项目提供了一键构建脚本，使用 CMake 自动完成项目配置和编译。

在编译之前，请确保已安装：
- **CMake**（建议 3.20 或更高版本）
- 对应平台的 C 编译器

根据操作系统选择对应的构建方式。

### 🐧 Linux / macOS

确保已安装 GCC 或 Clang，然后在项目根目录执行：

```bash
# 首次运行需要赋予脚本执行权限
chmod +x build.sh

# 执行构建
./build.sh
```

### 🪟 Windows

**Windows 平台必须使用 MinGW（GCC）进行编译，暂不支持 MSVC（Microsoft Visual C++）编译器。**

请提前安装并配置：
- CMake
- MinGW-w64（GCC）

确保 `gcc` 和 `cmake` 已添加到系统 PATH 环境变量中，然后在项目根目录执行：

```bat
build.bat
```

> **注意：**
> - 不支持使用 MSVC、Visual Studio 默认 C/C++ 工具链或 `cl.exe` 进行编译。
> - 使用 CMake 时，请确保选择 MinGW 对应的构建工具链。
> - 如果之前使用其他编译器构建过项目，请先清理旧的 `build` 目录，再重新构建。

## 构建说明

- 构建脚本会自动创建 `build` 目录。
- 自动执行 CMake 项目配置。
- 自动调用对应的构建工具进行编译。
- 支持增量编译，避免每次都重新构建整个项目。

编译成功后，生成的可执行文件及相关构建产物将存放在项目根目录下的 `build/` 目录中。
